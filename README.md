# CMMC 레벨 1 실습 시뮬레이터

가상 방산 협력업체 **가상정밀(주)**의 업무 PC와 사무실 네트워크를 점검·조치하고, 증거를 모아 자체평가와 SPRS 제출까지 연습하는 교육용 웹 시뮬레이터입니다. 설치 없이 브라우저에서 실행됩니다.

🌐 **실습 바로가기:** https://kongsu02-hue.github.io/cmmc/

## 실습 흐름

| 탭 | 내용 |
|---|---|
| 0 안내 | 레벨 1 규칙(32 CFR 170.15), 가상 회사 상황 |
| 1 범위 정의 | FCI를 처리·저장·전송하는 자산 고르기 |
| 2 PC 점검·조치 | 가상 PowerShell로 계정·권한·암호 정책·원격 데스크톱·공유 폴더·방화벽·업데이트·백신 점검과 조치, `\| Out-File`로 증거 저장 |
| 3 네트워크 | 설정에 따라 바뀌는 망 구성도와 장비 설정: **NAC**(MAC·802.1X 인증, 미등록 장치 차단·격리 VLAN 99, 유선 포트 적용), **경계 방화벽**(인바운드 기본 정책, 포트 포워딩, UPnP), **VLAN**(8포트 스위치 access/trunk, SSID→VLAN 매핑, DMZ), **ACL**(순서 적용 규칙, VLAN 간·아웃바운드 통제, 정책 시험), 공유기 관리·Wi-Fi 보안. 외부 포트 스캔, 망 분리 시험, 아웃바운드 시험 |
| 4 설정·문서 작업 | Windows 업데이트, 메일 2단계 인증, 외부 연결 규칙, 게시 승인 절차, 계정 대응표, 출입 권한자, 방문자 응대, 출입카드 대장, 매체 폐기 기록부 |
| 5 자체평가 | 15개 요구사항 MET/NOT MET 판정과 채점 |
| 6 SPRS 제출 | 제출 항목·확인서. 15개 모두 충족하고 조치 후 증거가 있어야 제출 가능(POA&M 불허) |

## 다루는 요구사항 (FAR 52.204-21, 15개)

AC.L1-b.1.i~iv · IA.L1-b.1.v~vi · MP.L1-b.1.vii · PE.L1-b.1.viii~ix · SC.L1-b.1.x~xi · SI.L1-b.1.xii~xv

## 특징

- 새 시나리오마다 결함 위치가 바뀌어 반복 연습 가능
- 조치 전에 수집한 증거는 "미충족 상태 증거"로 구분
- 관리자 권한 분리, C 드라이브 완전 삭제 차단 등 실습 안전장치
- 진행 상황은 브라우저에만 저장, 서버 전송 없음

> 모든 회사·계정·장비·네트워크는 가상입니다. 근거: 32 CFR 170.15, FAR 52.204-21, NIST SP 800-171. 암호 최소 8자 등 일부 기준은 교육용입니다. 실제 평가는 국방부 CIO의 레벨 1 평가 지침 원문을 따르십시오.
