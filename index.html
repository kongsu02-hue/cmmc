CMMC 레벨 1 실습 시뮬레이터

가상 방산 협력업체 가상정밀(주)의 업무 PC를 점검·조치하고, 증거를 모아 자체평가와 SPRS 제출까지 해 봅니다. 모든 상황은 가상이며 내 PC에는 아무 영향이 없습니다.

실습 안내

한글 실습 문서 「CMMC_레벨1_실습항목」의 6단계를 그대로 따라갑니다.

규칙 (32 CFR 170.15)

  • 보호 대상: 연방계약정보(FCI)
  • FAR 52.204-21 요구사항 15개, 매년 자체평가
  • 15개 모두 충족(MET)해야 함
  • 보완계획(POA&M) 불허 — 고친 뒤 제출
  • 임원 확인서 필수, 증거 6년 보관

가상정밀(주) 상황

  • 직원: 김대표(kim), 이과장(lee), 최사원(choi). 박대리(park)는 지난달 퇴사
  • 공용 계정 office를 사무실에서 같이 씀
  • 발주 메일로 받은 납품일정(FCI)을 김대표 PC에서 작성하고 공유 폴더·USB로 주고받음
  • 사무실 공유기 하나에 업무 PC, NAS, 복합기, 회사 소개 웹서버, 손님 Wi-Fi가 모두 연결되어 있음
  • 당신은 김대표 PC에 로그인한 상태 (PS C:\Users\kim)

진행 방법

  1. 범위 정의: FCI가 닿는 자산 고르기
  2. PC 점검·조치: PowerShell 명령으로 확인하고 고치기. | Out-File 파일명으로 증거 저장
  3. 네트워크: NAC, 경계 방화벽, VLAN·스위치 포트, ACL, Wi-Fi를 설정하고 포트 스캔·분리 시험으로 확인
  4. 설정·문서 작업: 메일·업데이트, 절차서와 기록부
  5. 자체평가: 15개를 직접 판정
  6. SPRS 제출: 모두 충족해야 제출 가능

점검 결과는 처음부터 여러 개가 미충족입니다. 증거는 조치한 뒤에 다시 수집해야 유효합니다. 조치 전 증거는 "미충족 상태 증거"로 표시됩니다.

1. 범위 정의

FCI를 처리·저장·전송하는 자산만 평가 범위에 넣습니다. 범위에 포함할 자산을 모두 고르세요.

2. PC 점검·조치 (가상 PowerShell)

명령을 입력하거나 오른쪽 힌트를 눌러 입력창에 넣으세요. help로 지원 명령을 볼 수 있습니다.

PS C:\Users\kim>

요구사항별 힌트

3. 네트워크

가상정밀(주)의 공유기·관리형 스위치 화면입니다. 지금은 모든 장치가 VLAN 1 한 망에 있습니다. NAC로 장치를 통제하고, 경계 방화벽 정책을 세우고, VLAN으로 망을 나눈 뒤 ACL로 VLAN 간·아웃바운드 통신을 정하세요. 결과는 외부 포트 스캔과 분리·아웃바운드 시험으로 확인하고 증거를 남깁니다.

설계 목표 (정답 기준)
영역목표 상태요구사항
NAC인증 방식 사용(MAC 또는 802.1X), 미등록 장치 차단·격리, 유선 포트 포함, 장치 8대 모두 등록 판단AC.i · IA.v · IA.vi
경계 방화벽외부→내부 기본 차단, 인바운드는 DMZ 웹서버 443만, UPnP 끔SC.x · AC.iii
VLAN업무 PC·NAS·복합기 = VLAN 10, 웹서버 = VLAN 30(DMZ), AP·업링크 = 트렁크, SSID GSJ-Office=10 · GSJ-Guest=20SC.xi
ACL손님→업무 차단, DMZ→업무 차단, 업무→DMZ 443 허용, 업무→인터넷 445·3389 차단, 손님→인터넷 443 허용SC.x · SC.xi

레벨 1 평가 목표상 SC.L1-b.1.x는 외부 경계와 주요 내부 경계 모두에서 통신을 감시·통제·보호해야 합니다. 이 실습에서는 VLAN 간 ACL이 내부 경계 통제입니다.

망 구성도

빨간 점선: 인터넷에서 들어오는 포트포워딩 · ⚠ 빨간 장치: 미승인·위험 · ⛔ 회색: 차단됨 · 빨간 테두리: 분리 안 됨

4. 설정·문서 작업

  
명령으로 할 수 없는 조치입니다. 완료한 뒤 📸 증거 저장을 누르세요.

  






  
4. 자체평가

  
요구사항마다 충족(MET) 여부를 판정합니다. 근거가 되는 증거가 있어야 합니다. 채점하면 실제 상태와 비교해 알려 줍니다.

  

  

  






  
5. SPRS 제출 모의

  
미 국방부 SPRS에 입력하는 항목과 임원 확인서입니다. 15개가 모두 실제로 충족되고 증거가 있어야 제출할 수 있습니다.
